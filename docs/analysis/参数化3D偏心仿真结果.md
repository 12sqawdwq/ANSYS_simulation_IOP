# 参数化 3D 偏心眼压计仿真 — 结果总结

## Parametric 3D Eccentric Tonometer Simulation

用**纯 APDL 参数化建模**（无需 Discovery/SpaceClaim）在服务器上完成的偏心测量研究。

---

## 建模方法

| 步骤 | 方法 |
|------|------|
| 几何 | APDL 代码：2D 截面 → VROTAT 旋转 360° 成 3D 实体 |
| 角膜 | 球冠壳，Mooney-Rivlin 超弹性 (C10=0.11, C01=0.025 MPa) |
| 眼睑 | 球冠层，Mooney-Rivlin (C10=0.076, C01=0.01 MPa) |
| 探头 | 圆柱，PLA 线弹性 (E=3500 MPa)，X 向偏心 |
| 网格 | SOLID187 四面体，0.3mm |
| 接触 | 探头-眼睑标准接触 + 眼睑-角膜 bonded |
| 载荷 | IOP=20mmHg 内压 + 探头压入 0.2mm |
| 关键约束 | 探头侧向 UX=UZ=0（防止偏心时侧滑飞脱） |

## 偏心测量结果

| X偏移 | 接触单元数(Ac代理) | 接触X跨度(mm) | 眼睑峰值应力(Pa) | 角膜峰值(Pa) |
|-------|-------------------|--------------|-----------------|-------------|
| 0.0mm | 351 | [-1.48, +1.48] 对称 | 27,148 | 49,135 |
| 0.5mm | 351 | [-1.48, +1.48] | 27,151 | 49,140 |
| 1.0mm | 337 | [-1.25, +1.48] 微偏 | 27,173 | 49,181 |
| 2.0mm | **180 (-49%)** | [-0.30, +1.48] 强偏 | **37,826 (+39%)** | 50,161 |

### 关键发现

1. **接触面积随偏心量减小**：351 → 180 单元（2mm 时减少 49%）
   - 与参考文档"2mm 偏移 Ac 减少超 45%"吻合
2. **接触区变不对称**：cx_min 从 -1.48mm 移到 -0.30mm，一侧"剥离"
3. **应力随偏心量升高**：小接触面积 + 相同力 → 局部应力集中
   - 眼睑峰值 27→38 kPa（+39%），云图峰值 49→151 kPa（3倍）

## 与坏掉的 CAD 模型对比

| | CAD 模型 | 参数化模型 |
|---|---------|-----------|
| 建模 | Discovery 手动，几何切向接触 | APDL 代码，接触几何正确 |
| 接触 | 永远张开(status=0)，零传力 | 咬合传力，351接触单元 |
| 偏心差异 | 全部一致（字节级） | 清晰趋势（面积-49%，应力+39%） |
| 求解 | 假象/穿模 | 4 case 全收敛 0 错误 |
