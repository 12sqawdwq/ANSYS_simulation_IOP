# 0–50 mmHg探头—IOP分式逆向回归结果

## 1. 目的

暂不通过 \(\eta_0、A_c、k_l、k_{c,0}、\alpha\)正向计算参数，而是直接使用已知FE输入IOP与扣除后探头读数，回归：

\[
P_{IOP}
=
\frac{bP_{probe}}
{1-aP_{probe}}
\]

本次使用0–50 mmHg、步长2.5 mmHg、0.259875 mm主工作点的全部21个实际FE点。

## 2. 回归方法

- 自变量：扣除后的 \(P_{probe}\)；
- 因变量：FE已知输入 \(P_{IOP}\)；
- 目标函数：直接最小化IOP空间中的未加权平方残差；
- 零点参与误差统计，但由于公式强制通过原点，不提供额外参数信息；
- 对每个候选 \(a\)，解析求取最优 \(b\)，再对 \(a\)执行一维剖面最小二乘搜索；
- 不使用 \(P_{IOP}/P_{probe}=b+aP_{IOP}\)线性化作为主回归，避免改变误差权重并排除零点。

## 3. 回归参数

得到：

\[
\boxed{
a=0.0653117307\ \mathrm{mmHg^{-1}}
}
\]

\[
\boxed{
b=1.8273148620
}
\]

因此回归公式为：

\[
\boxed{
P_{IOP}
=
\frac{1.8273148620\,P_{probe}}
{1-0.0653117307\,P_{probe}}
}
\]

名义回归标准误差为：

- \(SE(a)=0.00138542\ \mathrm{mmHg^{-1}}\)；
- \(SE(b)=0.0550371\)。

名义95%区间为：

- \(a\)：0.0624011–0.0682224 mmHg⁻¹；
- \(b\)：1.71169–1.94294。

这些区间只表示当前残差模型下的参数不确定度。FE点是确定性计算结果，不是独立实验重复，因此不能解释为真实硬件总体置信区间。

## 7. 解释边界

本次结果说明单个分式在整个0–50 mmHg范围内可以取得较高总体拟合度，但低压接触启用段仍是主要误差来源：2.5和5 mmHg均被低估约2.1 mmHg。

本次属于用户明确要求的“全部数据逆向回归”，因此新增2.5 mmHg中间点已经参与参数识别，不再是这组 \(a,b\)的独立盲验证点。后续生产算法必须使用新的独立FE或硬件金标准数据验证。

本次 \(a,b\)是探头—IOP关系的综合经验参数，没有分离：

\[
\eta_{eff},\quad A_c,\quad k_l,\quad k_{c,0},\quad \alpha
\]

所以不能把本次回归参数直接解释为上述任一单独物理量，也不能直接推广到其他眼睑厚度、推进量、角膜曲率或真实硬件。
