# Ae/Ac 实验差异与材料及眼压参数评估

> 状态说明：原报告使用球面相交面积构造外侧 $A_e$，由此得到的比例、误差和材料判断均已撤销。本文件保留为现阶段可执行的参数评估边界，不再给出伪精确的区间符合性结论。

## 1. 当前不能得出的结论

批次 `20260721T070542Z_6a75cde2_calibration_0p26` 固定眼睑材料倍率 `1.00`、角膜材料
倍率 `0.75`、IOP `20 mmHg`。此前使用的外侧面积为：

$$
r_{\mathrm{cut}}
=\min\left(2.16,\sqrt{2(7.8+t)\delta-\delta^2}\right),
\qquad
A_{\mathrm{cut}}=\pi r_{\mathrm{cut}}^2.
$$

这个量是未变形球面与推进平面的交线面积，不是有限元压平面积。由于它会被
$\min(2.16,\cdot)$ 截断到探头半径，原报告中薄端比例落入20%容差不能证明材料参数、
IOP或模型形式正确。

因此当前不能根据已有 $A_e/A_c$ 判断：

- 眼睑材料是否过硬或过软；
- 角膜材料是否需要继续降低到 `0.75` 倍；
- `20 mmHg` IOP是否导致比例偏移；
- bonded 界面是否是厚端误差的主因；
- `0.8-1.25 mm`、`1.5 mm` 或 `2.0 mm` 是否通过实验容差。

## 2. 仍可用于参数识别的观测量

已有求解中的下列量不依赖被撤销的球面相交面积：

| 观测量 | 主要约束对象 | 当前用途 |
|---|---|---|
| 探头力—位移曲线 | 眼睑与角膜的组合刚度 | 可用于材料参数反演 |
| 闭合接触面积和压力分布 | 外侧接触状态 | 接触与网格质检 |
| 外/内表面完整变形坐标 | 压缩传播与后续面积积分 | 新面积算法输入 |
| 角膜和眼睑应变场 | 局部变形模式 | 材料与边界条件比较 |
| 最大穿透量 | 接触数值质量 | 结果排除条件 |
| 中心与偏心横向反力 | 对称性和偏心敏感性 | 模型一致性检查 |

单一推进终点的峰值应力不适合单独反演材料；优先使用完整力—位移曲线和空间变形
轮廓，因为它们包含更多独立信息且不依赖人为面积边界。

## 3. 材料与 IOP 的后续评估顺序

1. 先完成形变场驱动的 $A_e$ 和 $A_c$ 定义，并在至少两档网格上检查面积稳定性。
2. 使用文献或实验的探头力—位移曲线约束组合刚度，不使用目标比例反推材料。
3. 固定材料后扫描 `15、20、25 mmHg`，检查IOP对预载形状、反力和内表面变形的影响。
4. 固定IOP后分别改变眼睑和角膜材料，利用力曲线与内外表面形变的不同敏感方向识别参数。
5. 最后比较 bonded 与有限切向滑移；只有可观测量明显改善且数值稳定时才增加界面复杂度。
6. 新面积和力学观测同时通过后，才与实验的厚度比例区间比较。
